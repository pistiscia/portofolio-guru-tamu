// PROFIL & BIOGRAFI

Semangat Berinovasi Melalui Rekayasa Perangkat Lunak

Halo! Nama saya Agafiel Pistiscia Torres, seorang siswa yang berdedikasi di jurusan Rekayasa Perangkat Lunak (RPL) SMK Telkom Lampung dengan minat mendalam pada pengembangan aplikasi web interaktif dan berdaya guna tinggi.

Di lingkungan SMK Telkom Lampung yang sarat dengan budaya teknologi dan kurikulum berbasis industri, saya terbiasa melatih logika komputasional, memecahkan permasalahan nyata dengan algoritma, dan membangun antarmuka web yang memikat pengguna. Saya memadukan estetika desain Sea Blue dengan kode bersih (Clean Code) agar setiap proyek tidak hanya sedap dipandang, tetapi juga cepat diakses dan mudah dipelihara.

Melalui program pelatihan dan workshop bersama Guru Tamu industri, saya dibimbing untuk memahami standar alur kerja profesional, mulai dari perancangan kawat (wireframing), pemodelan basis data terstruktur, version control menggunakan Git, hingga pengujian fungsionalitas aplikasi.
